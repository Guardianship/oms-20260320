========================================
       运维管理系统 - 使用说明
========================================

一、系统简介
-----------
这是一个简单易用的运维监控系统，可以监控：
- 本机Windows的CPU、内存、磁盘使用率
- 多台Linux服务器的CPU、内存、磁盘使用率
- 查看历史数据趋势图
- 数据保留最近7天

二、环境准备
-----------
1. 安装 Python 3.8 或更高版本
   下载地址: https://www.python.org/downloads/
   安装时请勾选 "Add Python to PATH"

2. 确保Linux服务器已开启SSH服务

三、首次启动
-----------
1. 双击 start.bat 脚本
2. 首次启动会自动安装依赖包（使用清华镜像源）
3. 等待服务启动
4. 打开浏览器访问: http://localhost:8000

四、使用说明
-----------
【实时监控】
- 自动每30秒刷新一次数据
- 绿色表示正常，黄色警告，红色危险
- 点击"查看历史数据"看趋势图

【服务器管理】
- 添加Linux服务器：名称、IP、端口(默认22)、用户名、密码
- 可以编辑和删除已添加的服务器

五、目录结构
-----------
oms/
├── backend/          # 后端程序
│   ├── app/          # 后端代码
│   ├── venv/         # Python虚拟环境(自动生成)
│   └── requirements.txt
├── frontend/         # 前端页面
├── data/             # 数据库文件(自动生成)
├── start.bat         # 启动脚本
└── README.txt        # 说明文档

六、常见问题
-----------
Q: 启动提示找不到Python？
A: 请安装Python并确保添加到PATH环境变量

Q: Linux服务器连接失败？
A: 检查网络、SSH是否开启、账号密码是否正确

Q: 如何停止服务？
A: 在启动窗口按 Ctrl+C

Q: 数据存在哪里？
A: 在 data/oms.db 文件中(SQLite数据库)

七、技术支持
-----------
如有问题，请检查:
1. Python版本是否 >= 3.8
2. 防火墙是否阻止8000端口
3. Linux服务器SSH是否正常
